# Ekran Görüntüleri

Ana README'nin "Ekran Görüntüleri" bölümü bu klasördeki dosyaları referans alır.
Aşağıdaki adlarla PNG ekleyin (canlı/demo uygulamadan, açık tema, ~1440px genişlik):

| Dosya | İçerik |
|-------|--------|
| `dashboard.png` | Ana panel — KPI kartları, "Dikkat Gerektiriyor", görev listesi |
| `risk-envanteri.png` | Risk envanteri — filtre çipleri, sıralanabilir tablo, renk+şekil skor rozetleri |
| `risk-detay.png` | Risk detayı — Fine-Kinney yaşam döngüsü stepper'ı |
| `risk-analitik.png` | Risk paneli — kategori bazlı içsel/kalan risk ve azaltım % |
| `dis-denetim-gantt.png` | Dış denetim planı — yıllık Gantt zaman çizelgesi |

İpucu (macOS): `Cmd+Shift+4` → `Space` → pencereye tıkla.
